# MATLAB GNSS Processing & Positioning Toolkit

A modular MATLAB implementation of the complete Global Navigation Satellite System (GNSS) signal-to-trajectory processing pipeline. This repository covers everything from coordinate reference frame transformations to precise relative positioning and Extended Kalman Filtering, accompanied by detailed technical reports and experimental results for each stage.

## Processing Pipeline Overview

### `01_Coordinates_conversion`
* **Focus:** Spatial reference frame transformations and topocentric projections.
* **MATLAB Implementation:** Conversions between Geodetic ($[\phi, \lambda, h]$), Earth-Centered Earth-Fixed (ECEF: $[X, Y, Z]$), and local East-North-Up ($\text{ENU}$) coordinate frames.
* **Documentation:** Detailed derivations of transformation matrices, ellipsoidal parameters (WGS-84), elevation, and azimuth angle calculations.

### `02_Coordinates_from_broadcast_ephemerids`
* **Focus:** Satellite orbit propagation from broadcast ephemeris parameters.
* **MATLAB Implementation:** Keplerian orbit solver (eccentric anomaly) and satellite clock correction computation in ECEF at exact signal transmission times.
* **Documentation:** Orbital mechanics derivations, clock adjustments, and verification against reference satellite orbits.

### `03_Atmospheric_corrections`
* **Focus:** Signal propagation delay mitigation along line-of-sight.
* **MATLAB Implementation:** Klobuchar ionospheric delay model and Saastamoinen tropospheric delay model with zenith mapping functions.
* **Documentation:** Analysis of atmospheric delay magnitude across elevation angles and sky plot visualizations.

### `04_Computation_of_receiver_position_from_code_pseudoranges`
* **Focus:** Single Point Positioning (SPP).
* **MATLAB Implementation:** Iterative Least Squares (ILS) solver estimating 4D receiver state ($[X, Y, Z, dt_r]$) using pseudorange observations.
* **Documentation:** Dilution of Precision ($\text{DOP}$) metrics, residual analysis, and convergence diagnostics.

### `05_Computation_of_rover_position_using_relative_positioning_with_code_and_phase_observations`
* **Focus:** Differential / Relative Precise Positioning.
* **MATLAB Implementation:** Double-differenced ($\text{DD}$) observation equations using code ($P$) and carrier-phase ($\Phi$) measurements to eliminate satellite and receiver clock errors.
* **Documentation:** Double-difference formulation, float ambiguity estimation, and relative baseline determination.

### `06_Kalman_Filtering`
* **Focus:** Sequential state estimation and trajectory smoothing.
* **MATLAB Implementation:** Extended Kalman Filter (EKF) tracking receiver position, velocity, and dynamic biases using kinematic process models.
* **Documentation:** Filter state-space definition, process/measurement noise tuning ($Q$ and $R$), and estimation error covariance analysis.
